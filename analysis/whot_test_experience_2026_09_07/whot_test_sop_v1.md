# WHOT 测试游戏标准化流程 V1

适用于 `test-h5.wajew.com` 测试环境、WHOT 6001 及后续同类纸牌游戏。目标是评估正常玩家体验、机器人策略、结算数值和可复现缺陷；不进行真实投注、提现、算牌、隐藏信息推断或奖励套利。

## 1. 测试前置

1. 核对域名必须是 `test-h5.wajew.com`，禁止误入 `wajegame.com` 生产站。
2. 使用已授权测试会话；不读取、保存或传输密码、OTP、Cookie、Token、账号标识。
3. 关闭促销、每日奖励和提现提示。遇到 `Toa pesa`/Withdraw 只点击关闭，记录为 UI 边界问题，不点击、不验证、不提交。
4. 新手任务、免费筹码、每日奖励不进入基线对局；如需验证奖励发放，单独使用 `bonus_credit` 批次并与 RTP/胜率样本隔离。
5. 进入首页第二张 `Whot Game` 卡片，或使用站内搜索的第一个标准 `Whot` 结果；不使用 BaccaWhot/Whot Duel 代替。
6. 为本次批次创建新的 `run_id`，不覆盖旧回执。

## 2. 每局采集

每局开始记录：

- 局次、策略组、机器人/真人标识（只记页面可见类别，不保存用户标识）；
- 页面显示下注单位、对手剩余牌数、我方手牌数、桌面顶牌；
- 匹配耗时、首屏加载耗时、网络延迟提示；
- 是否出现自动托管、暂停、动画卡住、重新连接提示。

每个我方回合：

1. 确认 `ZAMU YAKO`/我方回合提示；
2. 只从屏幕可见牌中选择合法牌，匹配数字或图案；
3. 没有可出牌时摸牌，记录摸牌次数；
4. 记录 `PICK 2`、`SUSPENSION`、`SOKO LA WOTE`、`WHOT`/特殊牌等事件；
5. 记录对手剩余牌数变化和机器人是否出现自动出牌提示；
6. 不使用脚本连点、隐藏牌、重复提交或客户端篡改。

## 3. 结算采集

结算页记录：

- `USHINDI`/`SHINDWA`/平局状态；
- 我方和对手的页面显示结算单位；
- 双方剩余点数、剩余手牌数量；
- 机器人是否先出完牌、是否触发同分/牌堆耗尽规则；
- 结算延迟、重复结算、返回房间失败等异常。

若出现提现提示：关闭弹窗并记录 `withdrawal_messaging_conflict`，不点击提现入口。

## 4. 策略分组

每组至少收集相同数量的局，避免把策略差异与样本差异混在一起：

| 策略组 | 规则 | 用途 |
|---|---|---|
| `first_legal_play` | 按手牌从左到右出第一张合法牌 | 基线 |
| `reduce_high_point_cards` | 合法时优先减少高点数牌 | 普通策略对比 |
| `retain_special_or_wild_cards_until_needed` | 不在无必要时提前出特殊/万能牌 | 资源管理对比 |

策略只允许使用公开规则和当前屏幕可见信息，不进行算牌或隐藏牌预测。

## 5. 机器人评估

每局记录以下行为：

- 是否遵守数字/图案匹配规则；
- 是否会在我方接近出完时使用可见的阻断或摸牌牌；
- 特殊牌使用是否与规则一致；
- 自动托管是否及时，是否出现长时间停顿；
- 是否出现非法出牌、重复扣款、重复结算或明显无意义操作。

机器人水平只根据足够样本评估，单局或少量胜负不能作为“智能”结论。

## 6. 指标和结论门槛

- 胜率：胜局数 ÷ 完整局数；
- 机器人胜率：机器人获胜局数 ÷ 机器人对局数；
- 页面显示结算分布：按策略组、对手类别和特殊牌事件拆分；
- 显示单位净变化：仅作测试数值，不直接当作资金；
- RTP：只有确认下注/返还字段语义、分母和结算口径后才计算。否则报告“显示单位比值”，不命名为正式 RTP；
- 100 局为最低基线，策略比较建议每组 30 局以上；低于此门槛只报告探索性结果。

## 7. 缺陷分级

- P0：出现真实资金路径、提现实际可执行、余额跨环境串用；立即停止并升级；
- P1：测试环境反复显示提现入口、结算重复/金额异常、非法牌或结果不一致；关闭提示并记录复现步骤；
- P2：机器人策略异常、自动托管卡住、动画/回合状态长时间不变；记录局次和截图；
- P3：文案、布局、可访问性或延迟问题；纳入体验报告。

## 8. 批次结束交付

每个批次至少输出：

- `run_receipt.json`：状态、局数、策略组、胜负、结算单位、机器人行为和缺陷；
- `experience_log.md`：可读的逐局摘要；
- `quality_checks.json`：局数、重复记录、缺失结算、环境边界和提现提示复现次数；
- 阶段报告：胜率、机器人行为、显示数值波动、缺陷清单和下一批策略安排。

不得把短样本胜率或显示单位净增解释成稳定获利，也不得把发现的测试配置问题用于套利。
