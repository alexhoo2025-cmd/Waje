# WHOT 双版本测试 SOP V3（可复用）

## 目标与样本边界

6001（旧版）与 9006（新版）分开建档；每版目标 100 个合格受控局。校准、托管、缺失结算、错误入口和规则不确定的对局只保留为观察证据，不计入策略比较。余额低于测试夹具设定的安全阈值时暂停新增正式局，不充值、不提现。

## 开局前门禁

1. 只绑定普通 Chrome 的现有登录标签，域名必须为 `test-h5.wajew.com`。
2. 通过首页可见 `data-game-id` 或站内搜索定位游戏；6001 必须回读 `/game/6001-whot`，9006 必须从真实卡片回读实际路由，禁止猜路径。
3. 关闭促销、任务和提现文案时只点击弹窗自身的 Close；不点击充值、提现、购买或需要付费的奖励。
4. 对应版本先完成规则/视觉校准，再领取正式策略槽位。浏览器锁屏、窗口不可见或前台验证失败时立即暂停，不能代填系统密码。

## DAU 1 快速启动

进入游戏路由后先启动本地可见画面观察器，再点击大厅 DAU 1。观察器只在识别到 WHOT 大厅且没有手牌/桌牌时点击一次固定校准点；下一帧必须出现发牌证据，否则停局。这样把“选房间到首次读取”的延迟降到一个捕获周期，减少自动托管。

## 回合状态机

`LOBBY → MATCHING → DEALING → OPPONENT_TURN → PLAYER_TURN → SPECIAL_RESOLUTION → SETTLEMENT`。

只有明确出现 `ZAMU YAKO` 才能点牌或牌堆。每个动作都绑定当前状态指纹；点击后等待连续两帧确认手牌/桌牌或特殊状态变化，动画期间不重复点击。牌型识别采用牌面小图标与主体连通域双重证据；仍未知就停，不随机点。

## 五秒决策预算

- 0–0.8 秒：一次画面捕获，读桌牌、手牌、对手牌数、倒计时和特殊状态；
- 0.8–1.0 秒：按数字/牌型/已认证特殊规则生成合法候选；
- 1.0–1.3 秒：使用本局预先固定的策略臂；
- 1.3–2.2 秒：一次点击并等待确认；
- 其余时间：最多一次受控重读，不盲目双击。

## 策略臂

- `first_legal_play`：从左至右第一张合法牌；
- `reduce_high_point_cards`：有普通合法牌时打出已认证点数最高牌；
- `retain_special_or_wild_cards_until_needed`：有普通合法牌时保留 WHOT/特殊牌，对手剩 1–2 张时才按已认证阻断规则处理。

一局内不得切换策略。比较前必须同版本、同人数、同房间和同下注档位，每组至少 25 局合格样本。

## 特殊状态

优先级为强制摸牌 → WHOT 五牌型选择 → Last Card 宣告/抓罚 → Suspension/Soko La Wote → 普通出牌 → 无牌可出时摸牌。只对已观察并可复现的状态编码规则；未认证状态保持 `unresolved`。

## 结算与质量

每局结算后立即保存胜负、结束原因、双方点数/牌数、下注显示、余额变化、托管标记、规则/视觉/控制器版本和证据哈希。自动托管局标记 `mixed_auto_play`；不以事后人工操作覆盖。正式 RTP 只有在下注、回报、费用和余额守恒字段认证后才计算 `SUM(gross_return)/SUM(stake)`。

## 恢复与停止

窗口失焦、屏幕锁定、路由变化、牌面识别失败、特殊规则不明、动作未确认、余额低于安全阈值或出现提现/充值提示时停止当前局并记录原因。恢复只重新绑定同一普通 Chrome 标签，不打开 PWA、地址栏、外部搜索或其他游戏。
