# 8月27—28日 Waje H5 TC 异常深钻｜阶段性诊断

## 结论

1. **8月27日的 Waje H5 TC 异常真实存在，且集中在 PAWAJEH5。** 按订单事实候选口径，PAWAJEH5 的完整日 TC 为 **101.36%**，较 8月21—26日平均 **79.98%** 高 **21.38 个百分点**。
2. **异常不是全产品共同上涨。** 8月27日 Android 主包为 **79.60%**、iOS 为 **77.88%**、Waje H5 Google Ads 为 **61.49%**；高值集中于 PAWAJEH5 的 `com.wajegame.web`（**101.59%**）和 `com.hfyl.special.h5`（**101.21%**）。
3. **Hilo / Plinko 不是主因。** Hilo 在高提现 H5 用户中只覆盖 3 人、已结算派奖 157,177.16；Plinko 只覆盖 5 人、派奖 386。相比同包 8,396,710.04 的成功提现，两者不足以解释异常。
4. **8月26日并非 PAWAJEH5 的日结异常。** 虽然10点钟 TC 一度为 106.36%，但完整日 TC 为 **75.57%**；后续时段充值累计快于提现，抵消了单小时波动。
5. **8月28日为日内集中打款信号，不是全天结论。** 仅有00:00—10:59数据；10点钟 `com.wajegame.web` 的成功提现 1,063,236.16、成功充值 427,220，小时 TC **248.87%**，抬高日内累计。金额分层中没有任何单一分组达到10人披露阈值，提示小群体或批量打款，但具体原因待账务与结算事实确认。
6. **目前最优先确认的是资金状态口径与高提现集中度。** 8月27日常规 H5 包的提现中，≥20k 的80名用户贡献约82.6%，其中14名 ≥100k用户贡献约49.5%。同时，候选成功充值之外仍有16.12M的 `type=1/status=4` 金额；该状态含义未认证，可能改变 TC 分母解释。

## 数据完整性

- **8月27日：完整日。** 00:00—23:59 共 24 个小时，作为本次主异常日。
- **8月28日：未完整。** 当前订单事实仅有 00:00—10:59 的 11 个小时。其同窗口 TC 为 88.23%，相对历史同窗口偏高但不能当作全天异常结论。
- 起源 BQ-TC详情截图的 WajeH5 结果与当前订单事实同为日内数据，但当前会话未能复现同一筛选的报表结果；因此报告不将两者的精确差异解释为业务变化。
