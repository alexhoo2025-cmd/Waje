# SQL执行说明

- `00_preflight.sql`：Metabase元数据与覆盖预检；可执行。
- `01`—`04`：V5指标逻辑草案。当前使用的`risk_recharge`只从2026-08-13开始有数据，无法覆盖主窗口，因此状态为`blocked_required_source`。
- 正式执行前，必须把首充CTE替换为企业BigQuery或数据开发认证的历史首充事实：一名用户一行，至少包含首次成功现金充值时间、金额、注册时间和渠道。
- `game_record`不能作为全量轻量化游戏事实；首局/局数/下注应切换到具备首次事件时间、合法局键和最终结算状态的认证游戏事实。
- 不得把空结果、查询超时或未映射游戏当作0。
