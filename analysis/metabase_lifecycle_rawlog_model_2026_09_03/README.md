# Lifecycle V2 Joint 原始日志日级聚合模型

远程 Metabase 已保存模型：`model_lifecycle_v2_joint_daily__rawlog_provisional`。

- 存放位置：`RobinRobin 的个人收藏集`，Model ID `240`。
- 原始来源：`whot_center.stat_lifecycle_pool_v2_log`。
- 固定过滤：`change_type = 3`、`data_type = 1`。
- 起始业务日：`2026-08-01`；使用次日快照计算 `business_date`。
- 输出粒度：`business_date × game_id × display_lifecycle`；仅有聚合值。
- 初次覆盖核验：2026-08-01 至 2026-09-02；每日 6,922—7,642 条源日志、29—32 个游戏、13 个生命周期值、49 类 `pool_type`。

## 可以使用的字段

- 已映射的游戏/厂商汇总名称、生命周期、完全/基础下注、实际/预期盈利、实际/预期 RTP；
- 充值、复充、提现、受控、绝对破产、留存、升级等原始日志可直接映射的日级累计指标；
- `data_cutoff_at`、`source_row_count`、`pool_type_coverage`、`metric_version`、`data_status`。

## 明确不可用的正式指标

下列字段统一标记为 `not_available` 或 `NULL`，不得用于正式看板 KPI、排序或推导：

- 历史软件版本、包体、分包渠道、归因媒体、归因渠道；
- 查询期去重用户数及人均类正式指标；
- TC 比、流充比、折损系数；
- 供应商、自研标识的全量认证维表；
- 新增用户口径和最终结算事实。

`display_lifecycle = -1` 是 `game_id = 0` 的全局汇总行；游戏与生命周期分析必须排除该行。正式生命周期分析使用 0—4，其他生命周期保留给数据质量核查。
