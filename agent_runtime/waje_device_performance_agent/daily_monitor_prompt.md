# 每日端侧数据健康与异常摘要

请针对最近 7 个完整 Africa/Lagos 自然日执行一次只读聚合诊断。

1. 先调用数据健康工具，确认 Android 三包、iOS 与 H5 的数据截止时间、完整日、延迟和质量状态。
2. 分别检查 Android 与 iOS 的原生轨迹 P95、网络 P95、HTTP 网络响应成功率、慢帧与冻结帧；只报告样本不少于 500 的 P95。
3. 仅按一个维度分别列出最多五项异常：设备型号、系统版本、国家、运营商或网络类型。不得跨端或跨包合并排行。
4. 报告 Android Crashlytics Fatal、Non-fatal 的去重事件量与问题数；不得生成率指标。
5. 报告 H5 已采集行为事件和 Web 性能缺口；所有未采集性能项应明确为 data_gap。
6. 输出一个短摘要：已证实异常、质量警告、数据缺口和最多三项行动建议。不得发送外部通知、写入 BigQuery 或输出明细。
