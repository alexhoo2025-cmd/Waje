# 轻量化游戏分析：研究结论与产品建议

## 一、研究范围

本条目整理“轻量化游戏分析”知识库当前可见内容，覆盖：

- H5 新注册用户点击游戏入口行为；
- 新注册玩家非 0 局游戏人数；
- 轻量化上线前后 0 局玩家占比；
- 综合结论及渠道差异；
- BC GAME PERYA COLOR GAME 数值分析与 COLOR GAME 改造逻辑；
- JADE 游戏改造；
- 轻量化游戏统一逻辑、免费玩家提现/充值引导和首充带币相关资料。

分析时间主要围绕 2026-05-11 轻量化上线前后，部分页面更新时间延伸至 2026-07-24。

## 二、核心指标结论

### 1. 点击意愿：上线后下降

综合结论页建议使用“新注册用户中点击游戏入口的用户占比”，而不是单纯看点击人数。

- 上线前（5/1—5/10，剔除 5/11、5/18）：点击用户占比大致在 52%—58%；
- 上线后（5/12—5/17）：点击用户占比下降至约 45%—49%；
- 点击人数上涨不能直接证明兴趣增强，因为新增规模、投放量和渠道流量都会影响人数。

### 2. 非 0 局玩家：小幅结构性提升

| 渠道 | 上线前非 0 局占比 | 上线后非 0 局占比 | 变化 |
|---|---:|---:|---:|
| `wajeh5` | 约 18.2% | 约 18.8%—19.0% | 约 +0.7pp |
| `wajebetH5` | 约 36.3% | 约 36.9% | 约 +0.6pp |
| `wajeh5pww` | 约 38.1% | 约 39.2% | 约 +1.1pp |

知识库结论认为：轻量化对非 0 局玩家占比有正向影响，但不是爆发式提升，更像结构性优化；高频玩家、11 局以上玩家和深度游戏用户占比增加，可能是轻量化更重要的价值。

### 3. 0 局玩家：首局门槛没有被长期降低

| 渠道 | 上线前 0 局占比 | 上线后 0 局占比 | 变化 |
|---|---:|---:|---:|
| `wajeH5` | 81.29% | 81.77% | 上升 0.48pp |
| `wajeh5pww` | 61.71% | 61.88% | 上升 0.18pp |
| `wajebetH5` | 63.63% | 63.73% | 上升 0.10pp |

`wajeh5pww` 在 5/11 当天曾从约 61.9% 降到 57.9%，但随后快速回升，说明存在短期新鲜感或尝试刺激，没有形成持续转化。`wajeH5` 长期 80%+ 的 0 局占比，是当前最严重的前链路问题。

## 三、综合判断

轻量化上线后，出现了“非 0 局占比小幅提升”与“点击意愿下降、0 局占比未改善”并存的现象。更准确的产品判断是：

1. 轻量化可能提升了部分已进入用户的持续参与深度；
2. 但没有稳定提升新用户点击入口和开始第一局的意愿；
3. 5/11 当天的改善更像短期新鲜感，未转化为长期行为；
4. 当前问题可能不是复杂度过高，而是轻量化同时削弱了刺激感、价值感和首局即时反馈；
5. `wajeH5` 还需要单独排查流量质量、误触、广告素材和入口吸引力，不能仅靠玩法改造解释。

## 四、渠道分层判断

| 渠道 | 观察 | 产品含义 |
|---|---|---|
| `wajeH5` | 0 局 80%+，点击占比下降 | 低意图流量、入口吸引力、加载/首局链路均需排查 |
| `wajeh5pww` | 上线初期改善，随后点击下降、0 局回升 | 有新鲜感但缺少长期价值和持续反馈 |
| `wajebetH5` | 非 0 局高位且整体稳定 | 用户原始游戏意图较强，轻量化影响有限，适合作为稳定基线 |

## 五、产品优化方向

### 1. 入口层

- 重新设计游戏入口美术和信息层级；
- 强调“赢、爽、秒开、高奖励”等价值感，不只强调“轻松、简单、休闲”；
- 让入口在低端机和 H5 首屏中快速加载并明确可点击反馈；
- 记录曝光、点击、点击后加载成功和实际进局，区分入口吸引力问题与技术失败。

### 2. 首局层

- 让用户更快进入第一局，减少金额、规则和玩法决策；
- 提供高频、明确的视觉和音效反馈；
- 重点优化 `点击 → 游戏加载 → 首局开始 → 首局结束` 链路；
- 增加首局完成率、首局耗时、首局失败原因和首局后继续游戏率。

### 3. 渠道层

- `wajeH5` 优先核查投放质量、误触和素材承诺与实际游戏的匹配度；
- `wajeh5pww` 验证新鲜感消退后的 D1/D3/D7 留存和 2 局以上比例；
- `wajebetH5` 作为高意图对照组，评估产品改造是否伤害原有转化。

## 六、COLOR GAME 与 JADE 的产品/数据风险

### COLOR GAME

资料定义了 3 个骰子、6 种颜色、最多同时下注 3 种颜色、固定单注金额和服务器端 RTP 配置。技术方案通过枚举 216 个结果、按 `e^(θ*Xn)` 生成权重，再用二分法求解 θ，使加权期望等于配置 RTP。

文档中的测试记录为：`R=0.8`、基础 RTP `0.9800925926`、`θ≈-0.1440507939`，18/18 testcase 通过，10000 局统计 RTP 误差小于 2%。这些是文档自述结果，后续仍需独立复核随机性、赔率、概率、结算和审计链路。

由于该方案影响概率、RTP、结算和玩家资金结果，按项目 PRD 分级规范应至少按 L3 + 游戏数值专项附录处理。

### JADE

改造包括正整数下注、服务端下发中奖倍率、未付费用户等级限制、未付费用户下注金额/次数限制、禁用 Auto、余额不足拦截、资产不足弹窗队列、音效和非洲本地化视觉。

这些规则会影响未付费用户分层、付费引导和游戏公平感，建议增加：规则版本、用户资格快照、服务端配置版本、拦截原因、Toast/弹窗曝光与点击、余额状态、投注金额和结算结果埋点。

## 七、当前工作结论

轻量化后续优化目标应从“继续降低玩法复杂度”调整为：

> 提高入口吸引力、降低首局决策成本、增强首局即时反馈，并验证用户是否持续对局。

真正的成功标准不应是点击人数增加，而应是：点击用户率、游戏加载成功率、首局开始率、首局完成率、2—3 局比例、11 局以上比例、D1 留存和首付率同步改善。
