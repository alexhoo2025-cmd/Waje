## 4. RTP 与难易度采集方案

每个玩法至少采集以下字段：

| 维度 | 采集内容 |
|---|---|
| 玩法机制 | 局/回合定义、目标、操作顺序、是否自动结算、是否多人共玩 |
| 资金机制 | 最小/最大下注、余额类型、Chip/BonusChip/Coin 是否可用、扣款时点 |
| 奖励结构 | 倍率、赔付表、连击/免费局/Bonus、Jackpot、封顶规则 |
| 概率信息 | 页面 RTP、理论 RTP 配置、命中率、波动、目标概率、抽样区间 |
| 体验难度 | 首次理解时间、操作步骤、失败反馈、规则透明度、弱网恢复 |
| 数据质量 | game_id、round_id、bet_id、result_id、stake、payout、currency、version |
| 异常 | 加载失败、余额不同步、重复扣款、结果丢失、奖励未到账、回退异常 |

### RTP 计算口径

```text
实测RTP = Σ payout / Σ stake
实测净回报率 = (Σ payout - Σ stake) / Σ stake
命中率 = 有派奖结果的局数 / 有效下注局数
```

实测结果必须按游戏、版本、币种、下注档位、用户类型和时间窗口切分；样本不足时只标记为观察值，不作为理论 RTP 结论。
