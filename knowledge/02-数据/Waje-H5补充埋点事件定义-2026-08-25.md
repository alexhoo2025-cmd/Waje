# 事件定义

适用范围：Waje H5 浏览器、PWA 独立运行、APP WebView。遵循现有 H5 上报签名：

```ts
getReqData(event_type, entry_id, page_id?, event_id?, params?)
```

- `entry_id`：沿用现有页面/模块入口映射；无既有映射时由 H5 负责人确认，不默认传 `0`。
- `event_id`：必须使用起源创建后的实际功能埋点 ID；本文件的 H5 专属事件均为**待创建**，不得用逻辑编码伪造实际 ID。
- `params`：仅上报本文件字段；对象数组的键结构沿用当前 H5 SDK 解析实现。
- 公共 SDK 属性不重复创建。H5 专属字段需登记在**事件属性**目录，不能只建在“功能埋点参数”目录。

## 公共上报字段

所有 H5 专属事件均携带；仅在当前 SDK 或平台已有对应字段时复用。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| event_name | string | 事件名称 | 与本节事件编码一致 |
| event_version | string | 事件契约版本 | 首版固定 `v3`；平台公共字段 |
| event_uid | string | 单条事件幂等键 | 重试必须复用，不得生成新键 |
| client_time_ms | string | 客户端上报时间 | 13 位毫秒时间戳 |
| session_id | string | H5 会话 ID | 匿名到登录不切换 |
| user_id | string | 登录用户 ID | 登录后上报；不得写入前端日志 |
| uuid | string | 匿名身份标识 | 未登录可上报；不等同 user_id |
| surface_type | string | 端形态 | `h5_browser`、`pwa_standalone`、`app_webview` |
| web_version | string | H5 构建版本 | 不得用 APP 版本替代 |
| release_id | string | 发布/灰度批次 | 平台公共字段；无值时按现有 SDK 约定 |
| sdk_version | string | H5 埋点 SDK 版本 | 用于版本排障 |
| page_id | string | 起源页面 ID | 页面/模块场景必填 |
| game_id | string | 稳定游戏 ID | 游戏事件必填；不得使用展示名称替代 |
| provider_id | string | 游戏供应商 ID | 自研/第三方区分 |
| channel | string | 分包/一级渠道 | 渠道可用时上报 |
| country | string | 国家代码 | ISO 代码，例如 `NG` |
| device_tier | string | 设备档位 | `low`、`mid`、`high`、`unknown` |
| memory_tier | string | 内存档位 | `le_2gb`、`gt_2_le_4gb`、`gt_4_lt_8gb`、`ge_8gb`、`unknown` |
| browser_name | string | 浏览器名称 | 规范化名称；不上传完整 UA |
| os_name | string | 操作系统名称 | 规范化名称 |
| network_type | string | 网络类型 | `wifi`、`cellular`、`ethernet`、`unknown` |
| effective_type | string | 有效网络类型 | `slow-2g`、`2g`、`3g`、`4g`、`unknown`；不可用时不上报 |
| measurement_state | string | 观测状态 | `complete`、`partial`、`not_supported`、`blocked`；禁止以 0 代替缺失 |
| is_retry | bool | 是否为重试/补发 | 首发为 false |
| retry_count | int | 重试次数 | 首发为 0，非负递增 |
| sample_rate | double | 采样比例 | 全量为 1；抽样必须填真实比例 |

## H5 会话开始事件：H5_SESSION_START

SDK 初始化完成后上报；每个 `session_id` 一次。实际 `event_id`：待起源创建。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| entry_source | string | 会话进入来源 | `direct`、`deeplink`、`ad`、`notification`、`app_bridge`、`other` |
| navigation_type | string | 首次导航类型 | `navigate`、`reload`、`back_forward`、`restore` |
| resume_from_background | bool | 是否从后台恢复 | 后台恢复为 true |
| referrer_host_key | string | 前向来源域名键 | 仅规范化 host；不上传完整 URL |

## H5 会话结束事件：H5_SESSION_END

在 `pagehide`、`visibilitychange` 等尽力发送；未收到结束事件不得推断为崩溃。实际 `event_id`：待起源创建。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| session_duration_sec | int | 会话有效时长 | 单位秒；仅有效结束样本填写 |
| last_stage | string | 结束前最后业务阶段 | `page_ready`、`game_loading`、`game_ready`、`bet_ready`、`bet_submit`、`settlement`、`payment` |
| close_reason | string | 会话结束原因 | `pagehide`、`background`、`user_exit`、`reload`、`unknown` |
| error_count | int | 会话内去重错误数 | 同一指纹多次发生只累计 |

## 页面关键就绪性能事件：H5_NAVIGATION_PERF

每次路由对应一条 `page_visit_id`；在关键内容 ready 或页面结束前发送最终值。实际 `event_id`：待起源创建。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| page_visit_id | string | 页面访问唯一 ID | 每次 SPA 路由唯一 |
| navigation_type | string | 导航类型 | `navigate`、`reload`、`back_forward`、`spa_route` |
| route_key | string | 页面逻辑路由 | 不传 URL 查询串 |
| ready_signal | string | 关键就绪信号 | `dom_ready`、`business_ready`、`container_ready` |
| critical_ready_ms | int | 关键内容就绪耗时 | 路由开始至 ready，单位毫秒；待登记为事件属性 |
| fcp_ms | int | First Contentful Paint | 能力可用时填写；不可用不上报 |
| lcp_ms | int | Largest Contentful Paint | 能力可用时填写；不可用不上报 |
| inp_ms | int | Interaction to Next Paint | 能力可用时填写；不可用不上报 |
| cls | double | 累积布局偏移 | CLS 累积值 |
| long_task_total_ms | int | 长任务总耗时 | 当前页面访问内，单位毫秒 |
| long_task_max_ms | int | 最大单次长任务耗时 | 单位毫秒 |
| resource_count | int | 页面资源总数 | 当前页面访问资源数 |
| critical_resource_count | int | 关键资源数量 | 关键路径资源数 |
| transfer_size_bytes | int | 实际传输量 | 跨域受限时不上报 |
| largest_resource_bytes | int | 最大资源大小 | 不记录资源 URL |
| timing_support | string | 可用性能能力集合 | `navigation`、`paint`、`lcp`、`inp`、`cls`、`longtask`、`resource` |

## 核心请求性能事件：H5_CORE_REQUEST

仅包装白名单内的 `fetch/XHR` 请求；HTTP 成功不等同于支付、下注或结算业务成功。实际 `event_id`：待起源创建。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| request_id | string | 单请求唯一 ID | 不得承载 URL 或请求正文 |
| request_kind | string | 请求业务类别 | `bootstrap`、`login`、`profile`、`balance`、`game_config`、`game_launch`、`bet_submit`、`bet_confirm`、`settlement`、`payment_create`、`payment_result`、`withdraw_create` |
| endpoint_key | string | 接口字典键 | 服务端维护；不传完整 URL |
| status_class | string | 请求终态分类 | `success`、`timeout`、`network_fail`、`server_fail`、`business_reject`、`client_cancel` |
| http_status | int | HTTP 状态码 | 仅收到响应时填写 |
| duration_ms | int | 请求总耗时 | 发起到终态，单位毫秒 |
| request_start_ms | string | 请求开始时间 | 13 位毫秒时间戳 |
| request_end_ms | string | 请求结束时间 | 13 位毫秒时间戳 |
| network_snapshot | string | 请求网络快照 | `network_type/effective_type` 轻量快照 |
| server_result_code | string | 服务端业务结果码 | 仅白名单/脱敏码；不传服务端详情 |
| is_critical_path | bool | 是否关键路径 | 页面、游戏或支付关键链路 |

## 游戏加载事件：H5_GAME_LOAD

同一 `game_load_id` 可多次上报开始、阶段、失败、超时和放弃；不得用游戏点击或 iframe 创建替代加载状态。实际 `event_id`：待起源创建。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| game_load_id | string | 一次游戏加载唯一 ID | 从游戏卡点击生成，贯穿加载链路 |
| launch_source | string | 游戏启动来源 | `game_card`、`recommendation`、`banner`、`deeplink`、`return`、`other` |
| stage | string | 当前加载阶段 | `container_open`、`logo_ready`、`assets_ready`、`script_ready`、`service_connected`、`game_ready`、`bet_ready` |
| status | string | 阶段状态 | `start`、`success`、`fail`、`timeout`、`abandon` |
| stage_duration_ms | int | 当前阶段耗时 | 阶段终态填写，单位毫秒 |
| elapsed_ms | int | 累计加载耗时 | 从 game_load_id 开始，单位毫秒 |
| cache_state | string | 缓存状态 | `cold`、`warm`、`cache_hit`、`cache_miss`、`sw_update`、`unknown` |
| transfer_size_bytes | int | 游戏加载传输量 | 跨域受限时不上报 |
| error_code | string | 加载错误码 | fail/timeout 时填写 |

## 游戏就绪事件：H5_GAME_READY

仅当游戏方或容器确认画面/配置可用时上报；没有确认回调时只能表示容器打开。实际 `event_id`：待起源创建。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| game_load_id | string | 对应加载唯一 ID | 必须关联 H5_GAME_LOAD |
| status | string | 就绪状态 | `success`、`fail`、`timeout`、`abandon` |
| elapsed_ms | int | 累计加载耗时 | 从 game_load_id 开始，单位毫秒 |
| game_ready_ms | int | 游戏就绪耗时 | 成功确认时填写 |
| ready_source | string | 就绪证据来源 | `game_callback`、`container_callback`、`verified_dom`；禁止 `assumed` |
| error_code | string | 就绪错误码 | fail/timeout 时填写 |

## 可下注状态事件：H5_BET_READY

余额、币种、限额、服务连接和下注控件均进入终态后上报。实际 `event_id`：待起源创建。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| game_load_id | string | 对应加载唯一 ID | 必须关联 H5_GAME_LOAD |
| status | string | 可下注终态 | `success`、`fail`、`timeout`、`abandon` |
| elapsed_ms | int | 累计加载耗时 | 从 game_load_id 开始，单位毫秒 |
| bet_ready_ms | int | 可下注耗时 | 到可下注或失败终态，单位毫秒 |
| balance_ready | bool | 余额是否就绪 | 已获取且可展示 |
| currency_ready | bool | 币种是否就绪 | 资产状态已确认 |
| limit_ready | bool | 投注限额是否就绪 | 限额/资格已确认 |
| connection_ready | bool | 游戏服务是否就绪 | 连接已确认 |
| bet_control_ready | bool | 下注控件是否可操作 | 五项 ready 全为 true 才能 success |
| not_ready_reason | string | 不可下注原因 | `balance`、`limit`、`connection`、`game_config`、`asset`、`ui`、`network`、`unknown` |
| error_code | string | 错误码 | fail/timeout 时填写 |

## H5 客户端错误事件：H5_CLIENT_ERROR

用于 JS、资源、接口、白/黑屏、长任务、重载和内存压力；同一会话、同一指纹首条完整上报，后续累计。实际 `event_id`：待起源创建。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| error_type | string | 错误类别 | `js_error`、`unhandled_rejection`、`resource_error`、`white_screen`、`black_screen`、`long_task`、`reload`、`memory_pressure` |
| stage | string | 错误发生阶段 | 加载阶段，或 `page_ready`、`login`、`payment` |
| error_code | string | 业务/网络/资源错误码 | 未知为 `unknown` |
| error_fingerprint | string | 脱敏错误指纹 | 禁止上传完整堆栈、请求体或用户输入 |
| error_source_key | string | 错误来源类别 | 规范化脚本/资源类别；不传 URL |
| is_recoverable | bool | 是否允许恢复 | 用于恢复引导 |
| occurrence_count | int | 同指纹累计次数 | 同会话累计 |
| screen_rule_id | string | 白黑屏检测规则 ID | 白黑屏场景填写 |
| screen_state | string | 屏幕状态 | `white`、`black`、`normal` |
| waited_ms | int | 达到规则阈值等待时长 | 白黑屏场景填写，单位毫秒 |

## 网络变化事件：H5_NETWORK_CHANGE

在离线、恢复在线或可识别切网时上报。实际 `event_id`：待起源创建。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| network_change_id | string | 单次网络变化唯一 ID | 每次变化生成新键 |
| change_type | string | 网络变化类型 | `offline`、`online`、`changed` |
| previous_network | string | 变化前网络类型 | 不可读为 `unknown` |
| current_network | string | 变化后网络类型 | 不可读为 `unknown` |
| offline_duration_ms | int | 离线持续时长 | online 时填写，单位毫秒 |
| current_stage | string | 网络变化发生时的业务阶段 | 用于关联页面/游戏/支付状态 |

## 恢复结果事件：H5_RECOVERY_RESULT

用户执行 retry、reconnect、reload 或 return 后，在恢复进入终态时上报。实际 `event_id`：待起源创建。

| 字段名 | 类型 | 字段说明 | 备注 |
|-|-|-|-|
| recovery_id | string | 一次恢复尝试唯一 ID | 每次恢复生成新键 |
| origin_id | string | 原异常/链路 ID | `request_id`、`game_load_id` 或 `network_change_id` |
| action | string | 恢复动作 | `retry`、`reconnect`、`reload`、`return` |
| result | string | 恢复结果 | `success`、`fail`、`abandon` |
| recovery_duration_ms | int | 恢复耗时 | 到终态的耗时，单位毫秒 |
| final_error_code | string | 最终错误码 | result=fail 时填写 |

## 实施前校验

1. H5 专属字段先在起源“事件属性”目录登记，再绑定元事件；`critical_ready_ms` 当前仅创建为功能参数，不能视为已可用字段。
2. 每个事件必须实际创建并回填 `event_id`，再由 H5 调用现有 `getReqData` 接口。
3. 事件入库后按 `event_uid`、`session_id`、`page_visit_id`、`game_load_id`、`request_id` 做去重与链路校验。
4. 服务端下注、结算、支付、提现和资产以服务端事实为准；H5 事件仅用于体验、入口和链路诊断。
