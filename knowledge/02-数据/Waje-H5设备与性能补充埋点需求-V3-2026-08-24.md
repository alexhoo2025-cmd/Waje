# Waje H5 设备与性能补充埋点需求 V3

> 仅保留研发埋点需求。适用于 Waje H5 浏览器、PWA 与 APP WebView；不适用于原生 APP 的 Crash、ANR 和原生性能指标。
>
> 公共属性由平台/SDK 自动继承，本方案不重复创建或逐事件绑定。新增逻辑事件以 Ares 实际 `event_id` 为准；未创建时必须保留“待创建”，不得使用逻辑编码冒充实际 ID。
>
> 与现有《页面埋点方式》同版式的研发采集表：[Waje H5 补充埋点需求（页面采集方案）](https://ksg964l11fam.sg.larksuite.com/sheets/YBwksyRY2hRHiwtThD8l86EzgXe)，包含 `说明`、`页面埋点方式`、`通用参数`、`自定义参数` 四个 Sheet。

## 1. 当前 Ares 创建与回填状态

### 1.1 已验证可复用的元事件

| 用途 | Ares 元事件 | 实际 `event_id` | 使用要求 |
|---|---|---:|---|
| 页面进入 | `PV` | `2855092` | 页面真实可见时上报 |
| 页面退出 | `PD` | `2184105` | 离开页面时上报；`event_duration` 单位秒 |
| 模块曝光 | `MV` | `1589607` | 模块进入可视区才上报 |
| 模块点击 | `MC` | `2199814` | 用户实际点击才上报 |

### 1.2 本轮创建进度

| 对象 | 当前状态 | 实际 ID / 属性状态 | 处理结论 |
|---|---|---|---|
| 10 个 H5 专属元事件 | 未创建 | 无 `event_id` | 等待“事件属性”创建/绑定权限后创建 |
| `critical_ready_ms` | 已创建为功能埋点自定义参数 | `Integer`；页面未展示独立数值 ID | 不能被元事件选择，当前不作为元事件有效字段 |
| 公共字段（如 `event_version`、`release_id`） | 平台已有 | 公共继承 | 不重复创建、不作为本轮阻塞项 |

**阻塞说明：** 当前账号可创建“功能埋点参数”，但元事件的“配置业务参数”只能选择“事件属性”目录中的字段；两套目录不互通。未完成字段绑定前，不创建空的 H5 元事件。

## 2. 范围、数据边界与公共契约

### 2.1 需要回答的问题

```text
H5 会话 / 页面进入
  → 关键内容就绪
  → 游戏加载 / 游戏就绪
  → 可下注或失败原因
  → 请求、错误、切网与恢复结果
```

用于定位版本、页面、游戏、设备档位和网络条件下的不可玩、加载慢、错误与恢复失败问题。

### 2.2 不采集

- 账号密码、Cookie、Authorization、请求/响应正文、完整 URL 查询串、广告标识符和精确设备指纹。
- 原生 Crash、ANR、设备温度或原生内存指标。
- 用 HTTP 200、按钮点击或 iframe 创建推断“下注成功”或“游戏已就绪”。

### 2.3 平台公共字段（继承，不重复创建）

所有 H5 事件必须随上报携带平台公共身份与治理字段；字段名称以 SDK/平台已存在定义为准。

| 字段组 | 必须包含的字段 | 规则 |
|---|---|---|
| 事件治理 | `event_name`、`event_version`、`event_uid`、`client_time_ms`、`is_retry`、`retry_count` | 同一事件重试复用 `event_uid`；时间为 13 位毫秒 |
| 会话与页面 | `session_id`、`page_visit_id`、`page_id`、`module_id`、`event_id` | SPA 每次路由生成新的 `page_visit_id` |
| 版本与端形态 | `surface_type`、`web_version`、`release_id`、`sdk_version` | `surface_type=h5_browser/pwa_standalone/app_webview` |
| 用户与业务 | `user_id`、`uuid`、`game_id`、`provider_id`、`channel`、`country` | 登录后优先 `user_id`；未登录可使用 `uuid` |
| 设备与网络 | `device_tier`、`memory_tier`、`browser_name`、`os_name`、`network_type`、`effective_type`、`measurement_state` | 不支持/无权限时留空并标记观测状态，不得以 `0` 伪造正常 |

## 3. 页面与模块复用要求

| 页面/模块 | 复用事件 | 实际 ID | H5 补充关联键 | 上报要求 |
|---|---|---:|---|---|
| H5 首页、登录、注册、商城、提现 | `PV/PD` | `PV=2855092`；`PD=2184105` | `session_id`、`page_visit_id`、`surface_type`、`web_version` | `PD.event_duration` 仅表示停留秒数，不表示加载耗时 |
| 游戏卡片 | `MV/MC` | `MV=1589607`；`MC=2199814` | `game_id`、`page_visit_id`、`entry_source`、`game_load_id` | 曝光需真实进入可视区；点击后生成同一 `game_load_id` |
| 重试、网络恢复、错误引导 | `MV/MC` | 同上 | `recovery_id`、`error_code`、`retry_count` | 必须与后续恢复/错误事件关联 |
| 游戏容器页 | `PV/PD` | 待 H5 提供真实路由后映射 | `game_load_id`、`game_id`、`provider_id` | 不创建占位页面或模块 |

## 4. 新增 H5 逻辑事件

| 逻辑编码 | 展示名 | Ares 实际 `event_id` | 触发时机 | 去重键 | 优先级 |
|---|---|---:|---|---|---|
| `H5_SESSION_START` | H5 会话开始 | 待创建 | SDK 初始化完成 | `session_id` | P0 |
| `H5_NAVIGATION_PERF` | 页面关键就绪性能 | 待创建 | 关键内容就绪或页面结束前 | `page_visit_id` | P0 |
| `H5_CORE_REQUEST` | 核心请求性能 | 待创建 | 白名单请求进入终态 | `request_id` | P0 |
| `H5_GAME_LOAD` | 游戏加载阶段 | 待创建 | 开始、阶段完成、失败、超时、放弃 | `game_load_id + stage` | P0 |
| `H5_GAME_READY` | 游戏就绪 | 待创建 | 游戏方或容器确认画面/配置就绪 | `game_load_id` | P0 |
| `H5_BET_READY` | 可下注状态 | 待创建 | 余额、币种、限额、连接、下注控件进入终态 | `game_load_id` | P0 |
| `H5_CLIENT_ERROR` | H5 客户端错误 | 待创建 | JS、资源、接口、白黑屏、长任务、重载 | `event_uid` | P0 |
| `H5_NETWORK_CHANGE` | 网络变化 | 待创建 | offline、online 或可识别切网 | `network_change_id` | P1 |
| `H5_RECOVERY_RESULT` | 恢复结果 | 待创建 | retry、reconnect、reload、return 进入终态 | `recovery_id` | P1 |
| `H5_SESSION_END` | H5 会话结束 | 待创建 | `pagehide`、`visibilitychange` 等尽力结束 | `session_id` | P1 |

## 5. 事件专属字段需求

字段首次登记到 **事件属性** 目录后，才能绑定到第 4 节元事件。类型以 Ares 当前支持的 `String / Integer / Boolean / Double` 为准。

### 5.1 会话事件

适用：`H5_SESSION_START`、`H5_SESSION_END`。

| 字段 | 类型 | 必填 | 枚举 / 规则 |
|---|---|---|---|
| `entry_source` | String | START | `direct/deeplink/ad/notification/app_bridge/other` |
| `navigation_type` | String | START | `navigate/reload/back_forward/restore` |
| `resume_from_background` | Boolean | START | 是否从后台恢复 |
| `session_duration_sec` | Integer | END 条件 | 有效结束样本的会话时长，秒 |
| `last_stage` | String | END 条件 | `page_ready/game_loading/game_ready/bet_ready/bet_submit/settlement/payment` |
| `close_reason` | String | END 条件 | `pagehide/background/user_exit/reload/unknown` |
| `error_count` | Integer | END 条件 | 会话内去重错误数 |

### 5.2 页面关键就绪性能

适用：`H5_NAVIGATION_PERF`。

| 字段 | 类型 | 必填 | 枚举 / 规则 |
|---|---|---|---|
| `navigation_type` | String | 是 | `navigate/reload/back_forward/spa_route` |
| `route_key` | String | 是 | 页面逻辑路由；不传查询串 |
| `ready_signal` | String | 是 | `dom_ready/business_ready/container_ready` |
| `critical_ready_ms` | Integer | 条件 | 路由开始至关键内容就绪，毫秒；当前仅功能参数，待注册为事件属性 |
| `fcp_ms`、`lcp_ms`、`inp_ms` | Integer | 条件 | 浏览器能力可用时上报；不可用不写 `0` |
| `cls` | Double | 条件 | 累积布局偏移 |
| `long_task_total_ms`、`long_task_max_ms` | Integer | 条件 | 当前页面访问的长任务耗时 |
| `resource_count`、`critical_resource_count` | Integer | 条件 | 资源总数与关键资源数 |
| `transfer_size_bytes`、`largest_resource_bytes` | Integer | 条件 | 不记录资源 URL；跨域受限则不填 |
| `timing_support` | String | 是 | 支持能力集合：`navigation`、`paint`、`lcp`、`inp`、`cls`、`longtask`、`resource` |

### 5.3 核心请求性能

适用：`H5_CORE_REQUEST`；仅包装配置白名单中的 `fetch/XHR`，不传完整 URL 或请求正文。

| 字段 | 类型 | 必填 | 枚举 / 规则 |
|---|---|---|---|
| `request_kind` | String | 是 | `bootstrap/login/profile/balance/game_config/game_launch/bet_submit/bet_confirm/settlement/payment_create/payment_result/withdraw_create` |
| `endpoint_key` | String | 是 | 服务端维护的接口字典 ID |
| `status_class` | String | 是 | `success/timeout/network_fail/server_fail/business_reject/client_cancel` |
| `http_status` | Integer | 条件 | 收到响应时填写 |
| `duration_ms` | Integer | 是 | 请求发起到终态耗时 |
| `request_start_ms`、`request_end_ms` | String | 是 | 13 位毫秒时间戳 |
| `network_snapshot`、`server_result_code` | String | 条件 | 轻量网络快照、脱敏白名单业务码 |
| `is_critical_path` | Boolean | 是 | 是否属于页面、游戏或支付关键路径 |

### 5.4 游戏加载、游戏就绪与可下注

适用：`H5_GAME_LOAD`、`H5_GAME_READY`、`H5_BET_READY`。不得用游戏点击、iframe 创建或 `GAMESTART` 代替实际 ready。

| 字段 | 类型 | 适用事件 | 必填 | 枚举 / 规则 |
|---|---|---|---|---|
| `launch_source` | String | LOAD | 是 | `game_card/recommendation/banner/deeplink/return/other` |
| `stage` | String | LOAD / ERROR | 是 | `container_open/logo_ready/assets_ready/script_ready/service_connected/game_ready/bet_ready` |
| `status` | String | LOAD / READY / BET_READY | 是 | `start/success/fail/timeout/abandon` |
| `stage_duration_ms`、`elapsed_ms` | Integer | LOAD / READY / BET_READY | 条件 / 是 | 阶段耗时与加载累计耗时 |
| `game_ready_ms` | Integer | READY | 是 | 仅确认游戏就绪时填写 |
| `bet_ready_ms` | Integer | BET_READY | 终态 | 加载开始至可下注/失败的耗时 |
| `ready_source` | String | READY | 是 | `game_callback/container_callback/verified_dom`；禁止 `assumed` |
| `balance_ready`、`currency_ready`、`limit_ready`、`connection_ready`、`bet_control_ready` | Boolean | BET_READY | 是 | 五项均为 `true` 才可记 `status=success` |
| `not_ready_reason` | String | BET_READY | 失败/超时 | `balance/limit/connection/game_config/asset/ui/network/unknown` |
| `cache_state` | String | LOAD | 条件 | `cold/warm/cache_hit/cache_miss/sw_update/unknown` |
| `error_code` | String | LOAD / READY / BET_READY | 失败/超时 | 统一错误字典 |

### 5.5 客户端错误

适用：`H5_CLIENT_ERROR`。

| 字段 | 类型 | 必填 | 枚举 / 规则 |
|---|---|---|---|
| `error_type` | String | 是 | `js_error/unhandled_rejection/resource_error/white_screen/black_screen/long_task/reload/memory_pressure` |
| `stage` | String | 是 | 加载阶段或 `page_ready/login/payment` |
| `error_code` | String | 条件 | 未知为 `unknown` |
| `error_fingerprint` | String | 是 | 脱敏哈希；禁止上传堆栈、用户输入、请求体 |
| `error_source_key` | String | 条件 | 规范化脚本或资源类别；不传 URL |
| `is_recoverable` | Boolean | 是 | 是否允许用户恢复 |
| `occurrence_count` | Integer | 是 | 同会话、同指纹累计次数 |
| `screen_rule_id`、`screen_state`、`waited_ms` | String / String / Integer | 白黑屏条件 | `screen_state=white/black/normal`；排除后台和主动退出 |

### 5.6 网络变化与恢复

适用：`H5_NETWORK_CHANGE`、`H5_RECOVERY_RESULT`。

| 字段 | 类型 | 适用事件 | 必填 | 枚举 / 规则 |
|---|---|---|---|---|
| `network_change_id` | String | NETWORK | 是 | 单次网络变化唯一键 |
| `change_type` | String | NETWORK | 是 | `offline/online/changed` |
| `previous_network`、`current_network` | String | NETWORK | 条件 | 规范化网络类型；不可读为 `unknown` |
| `offline_duration_ms` | Integer | NETWORK | online 条件 | offline 到 online 的时长 |
| `current_stage` | String | NETWORK | 是 | 网络变化发生时的业务阶段 |
| `recovery_id`、`origin_id` | String | RECOVERY | 是 | 恢复键及原 `request_id/game_load_id/network_change_id` |
| `action` | String | RECOVERY | 是 | `retry/reconnect/reload/return` |
| `result` | String | RECOVERY | 是 | `success/fail/abandon` |
| `recovery_duration_ms` | Integer | RECOVERY | 终态 | 恢复耗时 |
| `final_error_code` | String | RECOVERY | fail 条件 | 最终错误码 |

## 6. 研发实现与验收要求

### 6.1 实现顺序

1. 埋点管理员将第 5 节 H5 专属字段登记到“事件属性”目录，并允许绑定元事件。
2. 数据产品创建第 4 节的 10 个 H5 元事件；回填 Ares 实际 `event_id`。
3. H5 前端实现会话、页面、核心请求、游戏加载、错误、切网与恢复上报。
4. 游戏容器/游戏方提供真实 `game_load_id`、`ready_source` 与 `BET_READY` 回调；不接受推测 ready。
5. SDK 接入完成后，以 Chrome、Safari、PWA、WebView、弱网和加载失败场景做埋点测试。

### 6.2 最小验收标准

| 检查项 | 验收标准 |
|---|---|
| 实际 ID | 第 4 节每个逻辑事件均已回填 Ares `event_id` |
| 字段契约 | 字段名、Ares 类型、必填条件与枚举和第 5 节一致 |
| 链路 | `SESSION_START → NAVIGATION`、`GAME_LOAD → GAME_READY → BET_READY` 可按关联键连接 |
| 质量 | 必填字段完整率 ≥99.5%；同一 `event_uid` 重复率 ≤1%；链路关联率 ≥98% |
| 数据边界 | `measurement_state!=complete` 不进入性能分位数；不支持能力不以 `0` 上报 |
| 业务事实 | 真实下注、结算、订单成功仍以服务端事实为准 |
