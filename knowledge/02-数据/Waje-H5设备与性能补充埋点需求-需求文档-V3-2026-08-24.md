# Waje H5 设备与性能补充埋点需求 V3（需求文档）

> 面向：产品、数据产品、H5 前端、游戏前后端、数据开发、QA。  
> 本文定义“需要观测什么、何时上报、如何验收”；字段级实现见 [[Waje-H5设备与性能补充埋点需求-V3-2026-08-24]]。
> 飞书团队阅读版：[Waje H5 设备与性能补充埋点需求 V3（需求文档）](https://ksg964l11fam.sg.larksuite.com/docx/KMKBdtBiioYVFax7LW2lpgG4gBh)。

## 1. 背景与问题

H5 GA4 已持续入库访问、会话和部分注册/充值行为，但当前未观察到 Web Vitals、页面/游戏加载阶段、核心请求、前端错误、白黑屏或可下注信号。现有自动 Web 事件和 `PAGELOAD` 也无法提供可认证的加载阶段耗时。

结果是：团队能看到“有多少访问”，却无法回答“用户为什么未能进入可下注、首局或首充”，也无法判断低端机、弱网、版本或单游戏是否造成体验损失。

## 2. 目标、范围与非目标

### 2.1 目标

1. 形成访问 → 页面 ready → 游戏加载 → 可下注 → 首局/支付服务端事实的可追溯链路。
2. 按 H5 浏览器、PWA、APP WebView、版本、页面、游戏、设备与网络定位体验问题。
3. 把“真实为 0、无样本、能力不支持、字段缺失、延迟、断流”分开呈现。
4. 为发布门禁、线上异常告警和首局/首充转化诊断提供统一数据基础。

### 2.2 范围

| 范围 | 本期要求 |
|---|---|
| 运行形态 | `h5_browser`、`pwa_standalone`、`app_webview` 必须显式区分 |
| 页面 | 首页、登录/注册、商城、提现、游戏容器及其核心路由 |
| 游戏 | 游戏入口、加载阶段、画面 ready、可下注、首局关联 |
| 体验 | Web Vitals、关键内容 ready、资源/长任务、核心请求、JS/资源错误、白黑屏、断网和恢复 |
| 业务关联 | 首次下注、首局结算、首充仅以服务端事实确认 |

### 2.3 非目标

- 不将 APP 温度、ANR、原生崩溃和原生内存回收复制到 H5。
- 不采集账号、密码、Cookie、Token、请求/响应正文、完整 URL 查询串或精确设备指纹。
- 不用客户端点击、HTTP 200、游戏 iframe 创建或 GA4 充值次数认定业务成功。

## 3. 用户场景与可观察需求

| 场景 | 触发 | 系统应记录的结果 | 失败/边界要求 |
|---|---|---|---|
| 用户进入核心页 | 页面路由开始 | 页面关键内容 ready 耗时与 Web Vitals | 能力不支持必须标记，不填 0 |
| 用户点击游戏 | 游戏卡片点击 | 唯一 `game_load_id`、来源、游戏/厂家、加载开始 | 点击不等于已可玩 |
| 游戏加载 | 容器打开、资源/脚本/连接阶段完成 | 每阶段耗时、终态、失败码 | 失败、超时、放弃只能归一个主失败原因 |
| 用户可以下注 | 余额、币种、限额、连接和控件均就绪 | `BET_READY.success` 与可下注耗时 | 任一条件缺失必须记录原因 |
| 页面或游戏异常 | JS、资源、白黑屏、长任务、重载 | 脱敏错误指纹、阶段、是否可恢复 | 不上传完整堆栈、用户输入或 URL 查询串 |
| 用户断网或切网 | offline、online 或可识别网络变化 | 当前阶段、离线时长、恢复动作与结果 | 不把网络类型作为唯一弱网判断 |
| 用户提交下注/支付 | 客户端请求完成 | 过程耗时、网络/业务拒绝分类 | 最终成功由服务端下注/订单事实确认 |

## 4. 功能需求清单

| 编号 | 优先级 | 需求 | 可观察验收结果 |
|---|---|---|---|
| FR-01 | P0 | SDK 初始化时创建稳定 `session_id`，并显式写入端形态、H5版本、发布批次和 SDK 版本 | 匿名→登录不切换会话；核心字段完整率 ≥99.5% |
| FR-02 | P0 | 每个核心路由创建 `page_visit_id`，记录 `route_start → critical_ready` 和可用 Web Vitals | `PD.event_duration` 不进入加载指标；非完整观测不进入 SLA 分母 |
| FR-03 | P0 | 游戏点击创建 `game_load_id`，贯穿加载、GAME_READY、BET_READY、首注和首局 | `GAME_LOAD.start → BET_READY` 关联率 ≥98% |
| FR-04 | P0 | 游戏方或容器只在可验证回调后上报 GAME_READY；可下注需五项条件全部为 true | 不可用原因可定位到余额、限额、连接、配置、资源或 UI |
| FR-05 | P0 | 白名单核心请求记录类别、耗时、终态、重试和关联 ID | 不记录完整 URL、请求/响应正文；HTTP 状态和业务状态分开 |
| FR-06 | P0 | 全量采集客户端错误与白黑屏终态，并按会话/错误指纹限频 | 有规则版本、阶段、脱敏指纹；白黑屏不误含后台或主动退出 |
| FR-07 | P1 | 记录网络离线、恢复、变化与重试/重连结果 | 可计算恢复成功率和恢复耗时 |
| FR-08 | P1 | Ares 创建实际 page/module/event ID，映射逻辑事件并供埋点测试查询 | 每项实际 ID 已回填；参数名、类型、触发组合与文档一致 |
| FR-09 | P1 | BigQuery/Ares 建立接收、入库、异常、重复、延迟和服务端关联质量监控 | 无数据可区分真实 0、无样本、未接入、延迟和字段缺失 |

## 5. 页面、模块与事件需求

### 5.1 复用事件

| 对象 | 现有 ID | 事件 | 补充要求 |
|---|---|---|---|
| H5 首页 | `n9pixal64m` | `PV/PD` | 加 `session_id/page_visit_id/surface_type/web_version`；PD 只记录停留秒数 |
| 登录页 | `x8asb2sqh7` | `PV/PD` | 核心登录请求与 `trace_id` 关联 |
| 注册页 | `2w52yelknv` 等 | `PV/PD` | 加 `registration_step/page_visit_id` |
| 商城 / 提现 | `ijkbaricdx / vue16bnq1d` | `PV/PD` | 加 `payment_context/withdraw_context`；最终状态以服务端事实为准 |
| 游戏卡片 | 既有模块待核验 | `MV/MC` | 曝光必须真实可见；点击生成/透传 `game_load_id` |
| 重试、网络恢复、错误引导 | 待创建 | `MV/MC` | 与 `recovery_id`、`error_code`、`rule_version` 关联 |

### 5.2 新增逻辑事件

| event_code | 触发时机 | 核心 `param` | 核心 `custom` | 实际 Ares ID |
|---|---|---|---|---|
| `H5_SESSION_START` | SDK 初始化后 | `session_id` | `surface_type/web_version/release_id` | 待创建 |
| `H5_NAVIGATION_PERF` | 关键内容 ready 或页面结束前 | `page_visit_id/page_id/critical_ready_ms` | Web Vitals、资源、长任务、能力状态 | 待创建 |
| `H5_CORE_REQUEST` | 核心请求达到终态 | `request_id/request_kind/status_class/duration_ms` | `http_status/server_result_code` | 待创建 |
| `H5_GAME_LOAD` | 游戏开始、阶段、失败、超时、放弃 | `game_load_id/stage/status/elapsed_ms` | 缓存、资源量、错误码 | 待创建 |
| `H5_GAME_READY` | 画面/配置已由可验证来源确认 | `game_load_id/game_ready_ms` | `ready_source` | 待创建 |
| `H5_BET_READY` | 可下注或终态失败/超时 | `game_load_id/bet_ready_ms` | 五项前置条件、不可用原因 | 待创建 |
| `H5_CLIENT_ERROR` | JS、资源、白黑屏、长任务、重载 | `error_type/stage` | 脱敏指纹、规则版本、恢复性 | 待创建 |
| `H5_NETWORK_CHANGE` | offline、online、网络变化 | `network_change_id/change_type` | 前后网络、离线时长 | 待创建 |
| `H5_RECOVERY_RESULT` | 重试/重连/刷新/返回终态 | `recovery_id/origin_id/action/result` | 恢复耗时、最终错误码 | 待创建 |
| `H5_SESSION_END` | 页面卸载或后台切换的尽力终止 | `session_id/last_stage/close_reason` | 会话时长、错误计数 | 待创建 |

## 6. 字段规则

### 6.1 所有新事件必带

| 字段 | 类型 | 规则 |
|---|---|---|
| `event_name/event_version/event_uid` | String | 事件名、契约版本、幂等键；重试复用 event_uid |
| `session_id/client_time_ms` | String | H5 会话和 13 位毫秒时间戳 |
| `surface_type/web_version/release_id/sdk_version` | String | H5 浏览器、PWA、WebView 和构建版本不可缺失 |
| `device_tier/memory_tier` | String | `low/mid/high/unknown`；未知不进入低端机分母 |
| `browser_name/os_name/network_type` | String | 规范化结果；不保存完整 User-Agent |
| `measurement_state` | String | `complete/partial/not_supported/cross_origin_restricted/not_observable/not_applicable` |
| `is_retry/retry_count/sample_rate` | Boolean/Integer/Double | 全量、重试与抽样策略可回溯 |

### 6.2 游戏可下注的判定

`BET_READY.success` 必须同时满足：

- `balance_ready=true`
- `currency_ready=true`
- `limit_ready=true`
- `connection_ready=true`
- `bet_control_ready=true`

任一失败必须携带 `not_ready_reason=balance/limit/connection/game_config/asset/ui/network/unknown`。没有厂商/容器回调时只能记录“容器已打开”，不得标记 `GAME_READY` 或 `BET_READY.success`。

## 7. 指标与上线门槛

| 指标 | 算法 | 数据源 | 使用边界 |
|---|---|---|---|
| 页面关键内容 P75/P90 | `critical_ready_ms` 分位数 | H5 性能事件 | 仅 `measurement_state=complete` |
| 游戏可玩率 | `BET_READY.success ÷ GAME_LOAD.start` | H5 事件 | start→终态关联率 ≥98% |
| 可下注 P75/P90 | `bet_ready_ms` 分位数 | H5 游戏事件 | 成功与失败分列 |
| 核心请求成功率/P90 | `status_class` 与 `duration_ms` | H5 请求事件 | 网络成功不等于业务成功 |
| 白黑屏率 | 确认白黑屏 ÷ 对应进入量 | H5 错误事件 | 有规则版本和排除条件 |
| 首注/首充成功率 | 服务端成功事实 ÷ H5 过程分母 | 服务端 + H5 关联 | 不用点击或 GA4 金额代替 |

沿用现有轻量化游戏门禁：简单玩法 `BET_READY` P75 ≤3.0s、P90 ≤5.0s；动效玩法 P75 ≤4.0s、P90 ≤6.5s。白/黑屏、重复下注、重复扣款、错误结算任一出现即发布失败。

## 8. 验收与依赖

### 8.1 必测场景

1. Android Chrome、iOS Safari、PWA、APP WebView 访问核心页。
2. 游戏正常加载、资源/脚本失败、余额未就绪、主动退出、超时和断网恢复。
3. JS 错误、未处理 Promise、白屏/黑屏规则命中。
4. 首次下注、首局结算、充值请求与服务端最终事实关联。

### 8.2 数据质量门槛

- 核心必填字段完整率 ≥99.5%，重复率 ≤1%，P95 入库延迟 ≤15 分钟。
- `SESSION_START→NAVIGATION`、`GAME_LOAD→BET_READY`、H5→服务端下注关联率均 ≥98%。
- 版本字段覆盖 ≥98%；不足时不输出版本排行。
- 非 `complete` 样本不进入相应性能分位数和 SLA 分母。

### 8.3 依赖与开放问题

| 项目 | Owner | 需要确认 |
|---|---|---|
| Ares 实际 ID 创建 | 数据产品 / 埋点管理员 | 游戏容器页、性能模块与 10 个逻辑事件的实际 ID |
| H5 构建注入 | H5 前端 / 容器 | web_version、release_id、commit_id、surface_type |
| 游戏回调 | 游戏前后端 / 厂商 | GAME_READY、BET_READY、失败阶段和回调来源 |
| 规则配置 | 产品 / QA / 数据 | 页面 ready、白黑屏、超时、核心接口白名单的 rule_version |
| BQ 认证层 | 数据开发 | 企业库授权、表名、分区、时区与告警执行位置 |
