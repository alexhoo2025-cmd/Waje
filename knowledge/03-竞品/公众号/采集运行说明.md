# 公众号文章授权采集运行说明

## 数据源与授权

公众号文章只允许通过内容平台提供的只读授权 API 接入。API 地址和令牌通过环境变量提供：

```text
WECHAT_ARTICLE_API_BASE
WECHAT_ARTICLE_API_TOKEN
```

两项认证信息不得写入 `config/`、`data/`、日志、报告、知识库或提交记录。若 API 尚未接通，可把研发提供的授权 `.json`、`.jsonl`、`.html`、`.zip` 或 `.pdf` 放入：

```text
data/incoming/wechat/YYYY-MM-DD/
```

导出文件只应包含文章正文和公开元数据，不应包含 Cookie、密码、用户明细或后台凭证。

## 运行命令

```bash
# 安装到项目独立虚拟环境
python3 -m venv .venv-wechat
.venv-wechat/bin/python -m pip install -r requirements-wechat.txt

# 单日采集、解析
.venv-wechat/bin/python scripts/collect_wechat_articles.py --date YYYY-MM-DD
.venv-wechat/bin/python scripts/parse_wechat_article.py --date YYYY-MM-DD

# 周五生成本周周报
.venv-wechat/bin/python scripts/build_wechat_weekly_report.py --date YYYY-MM-DD
```

主任务 `scripts/run_daily_pipeline.py` 已接入每日采集和解析；星期五 19:33（Asia/Hong_Kong）额外生成公众号周报。无授权 API 或授权导出时，采集阶段生成 `degraded` 空批次，主情报流程继续运行。

## 输出位置

| 内容 | 路径 |
|---|---|
| 原始/标准化文章快照 | `data/raw/wechat/YYYY-MM-DD/` |
| 正文结构与分析标签 | `data/processed/wechat/YYYY-MM-DD/articles.json` |
| 单篇知识库笔记 | `knowledge/03-竞品/公众号/YYYY-MM-DD-*.md` |
| 专项周报 | `knowledge/03-竞品/周报/YYYY-MM-DD-博彩社交游戏公众号周报.md` |

## 内容解读边界

自动解析只提供标题、导语、章节、段落长度、表格、引用、图片宽高比、图表提示和指标关键词等结构化线索。文章事实、数据口径、推断和建议仍需人工复核；无法访问正文时不得根据 URL 参数猜测标题、主题、结论或图表。
