## 推荐阅读路径

1. 产品体验：先读产品总览，再读产品与体验分析报告。
2. 竞品与市场：先读 Waje 竞品分析，再核对 HTML 报告和 JSON 数据工件。
3. 数据分析：先读起源平台盘点、数据平台与报表，再查看埋点与数据上报地图。
4. 自动化任务：阅读每日情报管道说明，并检查项目根目录的 `scripts/`、`jobs/` 和 `data/`。
5. 外部文档：先读入库默认工作流；项目相关文档默认形成可追溯 Markdown 资料，并刷新知识图谱。

## 证据规范

- 结论区分事实、推断、建议和待验证项。
- 指标先记录口径、时间范围、粒度和来源，再使用数值。
- 产品和竞品动态记录采集时间、来源链接及可信度。
- 公开信息不能替代内部收入、流水、玩家资产和支付明细；内部数据需脱敏并遵循权限范围。
