# Lark 只读静默采集实施指南｜2026-08-11

## 目标

从指定 Lark 会话读取与 Waje 项目和当前职责相关的沟通内容，提炼为本地知识库条目；全流程不向 Lark 发送、回复、点赞或修改任何消息。

## 当前状态

- 本地只读采集、脱敏、去重、规则提取和 Markdown 入库骨架已完成。
- 配置文件：`config/lark_sources.json`。
- 采集脚本：`scripts/collect_lark_messages.py`。
- 提取脚本：`scripts/parse_lark_messages.py`。
- 联调入口：`scripts/run_lark_pipeline.py`。
- 知识输出：`knowledge/05-协同沟通/YYYY-MM-DD-Lark项目沟通提炼.md`。
- 待复核输出：`data/outputs/lark/YYYY-MM-DD/review-queue.json`。
- Lark 应用创建和指定会话授权尚未完成。

## 用户配合步骤

### 第一步：创建只读应用

在 Lark 开放平台创建自建应用，名称建议为“Waje 项目知识采集”。应用创建后暂不把 App ID、App Secret 或 Token 粘贴到聊天中。

### 第二步：申请最小权限

只申请指定会话的消息读取、会话信息读取等只读权限；不申请消息发送、回复、点赞、群管理和成员管理权限。具体权限名称以当前 Lark 审批页面为准。

### 第三步：确定会话白名单

只配置项目相关群聊，例如数据报表、产品需求、增长运营等。将会话 ID 和会话名称写入 `config/lark_sources.json` 的 `allowed_chats`，不要配置全量工作区。

### 第四步：安全注入凭证

凭证只通过本地环境变量或密钥管理注入：

```text
LARK_API_BASE
LARK_API_TOKEN
```

禁止写入 `config/`、`data/raw/`、日志、Markdown 和 Git。

### 第五步：联调验收

```bash
python3 scripts/run_lark_pipeline.py --date YYYY-MM-DD
```

验收要求：

- `outbound_actions=0`；
- 只读取白名单会话；
- 敏感字段被脱敏；
- 相关消息进入知识库；
- 低置信度消息进入复核队列；
- Lark 客户端无机器人消息或操作痕迹。

## 处理边界

- 本地只保存脱敏后的必要字段，不保存完整私人聊天记录。
- 发送密码、Token、Cookie、银行卡等敏感内容的消息不会进入正式知识库。
- 规则提取只做初筛；需求优先级、业务结论、负责人和截止时间需要人工确认。
- 未授权会话、无法读取的私聊和权限不足的群聊不通过其他方式绕过。
