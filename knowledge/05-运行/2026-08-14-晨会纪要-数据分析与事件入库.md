## 四、H5/PWA 数据链路的本次确认清单

本项不能只确认“SDK 已接入”，应逐层给出证据：

```text
H5/PWA 客户端
  → Firebase Analytics / Performance / 错误监控
  → 原始事件或导出层
  → BigQuery/统一事实层
  → 起源认证指标层
  → 设备—性能—转化专项看板
```

最小核验项：

1. H5 浏览器、PWA 独立运行、APP WebView 能否由 `surface_type` 准确区分。
2. 是否已有真实的页面加载、网络请求、自定义性能 trace、JS/白屏/重载异常样本；仅有 Analytics 活跃数据不代表 Performance 或错误监控已可用。
3. 是否能关联 `session_id`、`trace_id/request_id`、`web_version/release_id`、游戏、渠道和设备网络维度。
4. `H5_SESSION_START → H5_GAME_LOAD → H5_BET_READY → 首次下注 → 首局结算` 是否可计算漏斗，失败阶段是否可下钻。
5. 事件是否完成“接收—入库—认证指标”对账；无数据、延迟、字段缺失与真实 0 值必须分开展示。

后续每次晨会均按 [[会议纪要与事件入库规范]] 处理：
