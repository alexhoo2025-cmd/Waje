# 分析报告一页速查与措辞指南

这是主规范的速查表，不是另一套标准。完整规则见[主规范](报告排版与配色规范-2026-09-07.md)。

## 出稿前的九个问题

1. 首屏能否直接回答业务问题？摘要是否只有2—4个不同判断？
2. 重点对象是否保留合理对照，而非只有单端、单月或单类人群？
3. 规模、比例、分母、变化是否讲清？单位和百分点是否正确？
4. 本报告的人群、起点、端、业务日和币种是否按最后确认口径填写？
5. 每节是否都有“判断—证据—含义”，每张图是否紧邻解读？
6. 图形是否适合数据，图例、单位、最高/最低/最新或异常点是否可读？
7. 关键结论是否加粗，普通正文是否避免整段高亮？
8. 会改变结论的限制是否就在旁边，过程说明是否移出核心正文？
9. 检查、桌面/窄屏及飞书回读是否实际完成？没有完成的项是否保留真实状态？

## 选图速查

| 要回答的问题 | 首选形式 | 注意 |
| --- | --- | --- |
| 随时间怎样变化 | 折线 | 有足够观测点；标最高、最低、最新；静态记录不伪造趋势 |
| 谁更高、差多少 | 分组条形/横条 | 同量纲、从零开始；长名称横向更易读 |
| 总量由什么组成 | 堆叠条形 | 明确100%分母，未知部分单列 |
| 多组或批次哪里不同 | 热力图/对照表 | 样本、观察范围一致，未知不着色成0 |
| 两个量有什么关联 | 散点 | 标异常点名称和值，不把相关写成因果 |
| 流程如何分支 | 流程图 | 真正展示条件和出口，不用事件数量代替工作量 |
| 要精确查阅 | 表格/附件 | 单位放表头，关键识别列靠左，长表内部滚动 |

## 措辞对照

| 修改前/易误解表达 | 建议表达 | 使用边界 |
| --- | --- | --- |
| Executive Summary | 执行摘要 | 产品名和必要缩写不机械翻译 |
| 需求合同分布 | 数据指标覆盖范围 | 若数的是文档条目，应说明覆盖计数，不冒充线上事件量 |
| 不产生双终态 | 每次请求只有一个最终结果 | 保留服务端裁决的条件 |
| 不因点击引导就记录提现成功 | 引导点击、提现申请和实际到账分别统计 | 不暗示它们可以合并 |
| 入口冻结分组不被事后充值改写 | 入口分组保留进入时状态；后续变化另行记录 | 防止未来信息污染 |
| 不能当局提前使用 | 权益从下一局开始使用 | 仅在原业务规则确实如此时使用 |
| 未成熟 | 尚未达到第30日观察天数 | 同时保留N/A，不变成0 |
| 付费率从50%降至40%，下降10% | 下降10个百分点，相对下降20% | 两种变化不能混称 |
| PP更好/某端更差 | 指定窗口、同口径指标较高/较低 | 解释未知，不直接给产品因果定论 |
| 成功支付率 | 付费率／订单支付成功率 | 先看分母：用户比例与订单成功率是不同指标 |

上述表是改写指导，不执行全局搜索替换。安全边界、数据不可比说明和隐私禁止条款保留。

## 固定与不固定

**固定：** 中文默认、结论先行、合理对照、来源可定位、必要限制可见、单列与可读字号、语义配色、真实验收。

**按报告填写：** 新用户定义、留存起点、回访行为、渠道与实际端、业务日、币种、资产、样本、比较范围、章节数量与图表数量。四类骨架不固定业务结论。
